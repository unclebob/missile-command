# Sound credits

Original Atari *Missile Command* arcade/console audio is copyrighted and is
**not** redistributed here.

These short effects are converted to mono 22.05 kHz WAV for the game from
**Apple Loops** sound libraries installed on this Mac (iLife Sound Effects and
Final Cut Pro Sound Effects under `/Library/Audio/Apple Loops/Apple/`).

| Game event | File | Source clip |
|------------|------|-------------|
| launch | `launch.wav` | FCP Sci-Fi / Laser Gun FX 01 |
| explosion | `explosion.wav` | FCP Sci-Fi / Factory Hit FX |
| city-destroyed | `city-destroyed.wav` | iLife Booms / Synth Zap Impact |
| battery-destroyed | `battery-destroyed.wav` | iLife Booms / Slamming Metal Lid |
| low-ammo | `low-ammo.wav` | iLife Sci-Fi / Computer Data 01 |
| wave-clear | `wave-clear.wav` | iLife Stingers / Electro Beep Accent 03 |
| bonus-city | `bonus-city.wav` | iLife Stingers / Synth Zap Accent 06 |
| the-end | `the-end.wav` | iLife Sci-Fi / Warp Engineering 01 |
| ui | `ui.wav` | iLife Sci-Fi / Computer Data 04 |

Apple Loops are subject to Apple’s software license terms for content created
with Apple software. Do not treat these as Atari ROM samples. Previous Mixkit
previews are kept under `tmp/sfx-mixkit-backup/` if a swap-back is needed.
